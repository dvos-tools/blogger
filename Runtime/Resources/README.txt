BLogger Package Resources
=========================

BLoggerConfigTemplate.asset
---------------------------
This is a READ-ONLY template file included with the package.

DO NOT EDIT THIS FILE - Your changes will be lost when the package updates.

Instead, the package automatically creates a copy at:
  Assets/Resources/BLoggerConfig.asset

You can also manually create a copy via:
  Tools > BLogger > Create Config (if missing)

This template serves as:
- A backup with sensible defaults
- A reference for available settings
- The source for auto-generated project configs

Canvas.prefab
-------------
The default on-screen terminal UI prefab. Referenced by the config.
