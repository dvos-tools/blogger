# Blogger ( Better Unity Logger )
blogger is suppose to support developement of unity games by adding a "better" logging system than the standart "Unity.Debug".

The goal is to support the following systems:
- File logging.
- In game logging screen
- Disabling itself based on build profile
- Jaeger support for live multiplayer builds

> [!CAUTION]
> This system is still in VERY early development. It will be unstable until V1
